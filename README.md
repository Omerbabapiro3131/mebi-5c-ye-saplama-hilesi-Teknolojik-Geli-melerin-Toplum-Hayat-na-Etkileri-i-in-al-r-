MEBİ Hız Testi Botu
Bu proje, MEBİ platformundaki hız testi etkinliklerini otomatik çözen bir javascript kodudur.

Linkler
Site adresi: 5cyiyenek.vercel.app

GitHub içeriği: Sitenin kaynak kodları ve kullanım rehberi.

Nasıl Kullanılır?
Site iframe yapısını kullandığı için botun çalışması için şu adımları yapmalısın:

F12 ile konsolu aç.

Konsolun üstündeki "top" yazan menüye tıkla.

Listeden "frmSkillBasedApp (index.html)" seçeneğini seç.

Kodu yapıştırıp Enter'a bas.

Not
Sadece nasıl çalıştığını göstermek için hazırlanmıştır. Kaynak kodları herkese açıktır.
